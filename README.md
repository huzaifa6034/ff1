
# Deployment Guide

### 1. Database (D1) Setup
1. Log in to Cloudflare Dashboard.
2. Go to **Workers & Pages** > **D1**.
3. Create a new database named `ff_tournament_db`.
4. Run the provided `schema.sql` inside the D1 console to create tables.

### 2. Backend (Worker) Setup
1. Use `wrangler` CLI to deploy the worker.
2. Add the D1 binding to your `wrangler.toml`:
```toml
[[d1_databases]]
binding = "DB"
database_name = "ff_tournament_db"
database_id = "<your-db-id>"
```
3. Run `wrangler deploy`.

### 3. Frontend (Pages) Setup
1. Upload the `dist` folder generated by your build tool (or just the static files if using vanilla) to **Cloudflare Pages**.
2. Point your API calls in `services/api.ts` to your Worker URL.

### 4. Default Admin Credentials
- **Username:** `admin`
- **Password:** `admin123`
*(Change these in the D1 database after first login)*
